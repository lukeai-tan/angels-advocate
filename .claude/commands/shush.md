description: Stop any in-flight Angel's Advocate speech immediately (mute the voices).

Run `tools/shush.sh` from the project root to stop any currently-playing verdict audio.
Report its output. Do nothing else — this is only a mute button.

Note for the user: the fastest way to mute is to type `! tools/shush.sh` directly in the
prompt (the `!` runs it in the shell instantly, without a round-trip through the model).
